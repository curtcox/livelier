# Keyboard and touch

| Action | Keyboard or gesture |
| --- | --- |
| Run main script | Ctrl/Cmd+Enter |
| Open halo | Alt/Option-click, Ctrl/Cmd-click, or 500 ms long-press |
| World or morph menu | Right-click; long-press the world background |
| Close halo/menu | Escape |
| Undo direct edit | Ctrl/Cmd+Z |
| Redo direct edit | Shift+Ctrl/Cmd+Z |
| Workspace do it | Ctrl/Cmd+D |
| Workspace print it | Ctrl/Cmd+P |
| Workspace inspect it | Ctrl/Cmd+I |
| Move a morph | Drag a draggable morph or its Move halo handle |
| Reparent | Drag a grabbable morph or the Grab halo handle into a drop container |
| Zoom world | Pinch with two fingers, 0.25×–4× |
| Pan world | Drag with two fingers |
| Reset view | Fit |
| Resize editor | Drag the splitter; focus it and use Left/Right |

On phones, use the World, Code, and Console tabs. Halo mode makes a single tap select a halo. Tap editable Text to bring up the keyboard. Controls and inputs use a minimum 40 px touch target on the phone layout.
