# Sharing and saving

Share embeds the main script and saved world in a link. Choose Don’t run on open to add ?run=0. A compressed main-only link uses ?compressed=; a document link uses ?doc=. The long form is URL-encoded text after #. A #CID link loads from HashBin; ?example=id opens a gallery sample.

A shared link includes the saved world. Scripted morphs are regenerated by the main script. Use Keep in world before sharing a scripted morph you want to preserve as a saved object.

## HashBin

The editor loads and verifies public CIDs from https://256t.us/. Small CIDs contain their content inline. Larger ones include the content’s SHA-512 hash; substituted bytes are rejected. The complete document limit is 5 MiB.

Save to HashBin opens an approval flow on hashbin.org; the editor never receives a sign-in credential. HashBin shows retention and price before approval. A redirect preserves source and world on success, cancellation, or failure. Until the Livelier app’s public client ID is configured, saving says HashBin saving needs a registered client ID. Loading is available without registration.

Register Livelier at https://hashbin.org/developers with return URL https://curtcox.github.io/livelier/ and place the public client ID in index.html’s hashbin-client-id meta tag. Keep the lowercase path and trailing slash.

## Short links and QR

Shorten link uses is.gd through AllOrigins with a bounded request timeout. Failures retain the full link and explain how to use HashBin instead. Links reveal their encoded program to those services when shortening is requested.

QR offers SVG and PNG downloads. Dense codes and long links show a HashBin suggestion. A localhost QR points at your own computer and cannot usually open on a phone. A saved CID link is reused while the program still matches that save; editing the world or source creates a new document link.

## Downloads and offline

Download exports livelier.json, main.js, world.svg, world.png, and console.txt. Open .json / .js restores a local file. SVG contains static shapes and text; HTMLMorph content has no active HTML in the export. PNG rasterizes the SVG through a browser image and never executes scripts in the editor.

After the entire offline cache verifies, More shows Available offline. The editor, tools, docs, gallery, and samples then work without a network connection. Remote images, fetch calls, HashBin, and link shortening still need the network. Update and reload first requests a fresh world snapshot and saves the local draft.
